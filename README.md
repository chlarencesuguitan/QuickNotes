QuickNotes
A simple productivity android application that combines the functionality of a note taking app and a todo list app.

#Key Features
1. Create, edit, and delete notes
2. Clean and minimal UI
3. Local data persistence
4. Offline-first functionality

#Tech Stack
Language: Kotlin
Platform: Android

#Learned
1. Developed Android applications using kotlin
2. Manages local data
3. Handling user interaction and lifecycle events
